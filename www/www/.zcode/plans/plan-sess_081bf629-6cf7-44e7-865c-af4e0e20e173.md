### B. Faz 3 — Native Desktop Özellikleri (`desktop-app/main.cjs` + `preload.cjs`)
7. **Native Menüler (Win/Linux)**: `Menu.setApplicationMenu(null)` yerine gerçek app menü şablonu (File/Edit/View/Window/Help) ekle; macOS mevcut menüsünü genişlet; dock menüsü (macOS) ekle. Rol bazlı (`role: "undo"`, `"quit"`, vs.) platform-uyumlu.
8. **Native Notifications (genişlet)**: sunucu çökmesi (`serverProc.on("exit")`) ve güncelleme mevcudiyetinde native Notification göster (`Notification.isSupported()` kontrolüyle)
9. **Native Dialogs (save)**: `dialog.showSaveDialog` için bir IPC handler ekle (`nx:save-dialog`) + preload bridge; export/dışa aktarım akışlarında kullanılabilir hale getir
10. **High DPI**: `webPreferences`'e `zoomFactor` politikası + `app.commandLine.appendSwitch` ile DPI-related flag'ler; `enableLargerThanScreen: true` ve retina-friendly ayarlar
11. **Fast Startup**: server spawn'ını `ready-to-show` sonrasına ertele (window önce gösterilir, server arka planda ayağa kalkar); gereksiz eager require'ları gerektiğinde lazy `require()`'a taşı
12. **Stable Memory**: window listener'larını `win.on('closed')`'da tutarlı şekilde temizle; `webContents`'i destroy et; sunucu process teardown'ını pekiştir
13. **Auto-Update**: `electron-updater` paketi ekle (gerçek bağımlılık, onaylandı); `autoUpdater` entegrasyonu (`checkForUpdatesAndNotify`), `publish` config (GitHub Releases, env-driven token), menüye "Güncellemeleri Kontrol Et", güncelleme akışı için native Notification + IPC. main.cjs + preload.cjs + yeni `updater.cjs` modülü.

### C. Faz 3 — Code Signing Altyapısı (sertifikasız config)
14. **`desktop-app/package.json`** electron-builder `build` bloğuna env-driven signing config ekle:
    - Windows: `signtoolOptions` / `WIN_CSC_LINK` + `WIN_CSC_KEY_PASSWORD` (secret yoksa atlanır)
    - macOS: `notarize` block (`afterSign` hook), `hardenedRuntime: true`, entitlements, `appleId`/`appleIdPassword`/`teamId` env-driven
    - `afterSign` hook script'i (`scripts/notarize.cjs`) env kontrolüyle koşullu çalışır (sertifikasız build'i bozmaz)

### D. Faz 3 — Build Pipeline Düzeltmeleri
15. **`packages/server/package.json`**'a esbuild devDependency + `build` script ekle: `esbuild src/main.ts --bundle --platform=node --format=cjs --outfile=dist/main.cjs` (+ .js ESM varyantı). `scripts/build-server.mjs` root'ta.
16. **`desktop-app/package.json`** sahte devDependencies → **gerçek** `electron` + `electron-builder` + `electron-updater`; `files` listesine `server/**` (bundle) ve `desktop-html/**` (kopyalanmış HTML) ekle; `extraResources` ile server bundle + desktop HTML'i `process.resourcesPath`'e paketle
17. **Root `package.json`**'a gerçek `build` script ekle (CI'nın çağırdığı): `pnpm build:static && pnpm --filter @nexus/server build && node scripts/copy-desktop-resources.mjs` (server + HTML'i desktop-app içine kopyalar)
18. **`scripts/copy-desktop-resources.mjs`** yeni: `packages/server/dist` → `desktop-app/server/`, `packages/desktop/dist` → `desktop-app/desktop-html/`

### E. Faz 3 — CI/CD (3-OS Matrix Release Workflow)
19. **`.github/workflows/desktop-release.yml`** yeni: `strategy.matrix` (windows-latest / macos-latest / ubuntu-latest), her OS kendi native build'ini üretir (Win: NSIS + portable, macOS: DMG, Linux: AppImage + deb). SHA-256 checksums + artifact upload. Signing secret'ler env-driven (varsa aktive olur). `tags` ile tetiklenen gerçek Release yayını.
