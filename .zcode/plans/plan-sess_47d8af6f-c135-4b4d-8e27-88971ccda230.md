## Hedef
NEXUS AI monoreposuna, mevcut premium HTML mobil UI'sını (`packages/mobile/src/index.ts` → `public/mobile/index.html`) birebir saran **gerçek Android + iOS uygulamaları** eklemek. Kodun kendi yorumunun önerdiği yol: WebView kabuğu (Capacitor). Tek tasarım kaynağı korunur — iki ayrı kod tabanı yazılmaz.

## Gerçekler (araştırmadan)
- `public/mobile/index.html` (~89 KB) tamamen kendi kendine yeten tek dosya: gömülü CSS + JS, harici istek yok.
- Tek sorun: font yolları root-relative (`/fonts/...`). Capacitor WebView'de göreceli (`./fonts/...`) olmaları gerekiyor → bundle adımında rewrite edilecek.
- Android SDK hazır (WHPX hızlandırma OK, 2 AVD var: `pixel_8_api_36`, `codex_pixel_api36`). Sadece PATH'te global Gradle yok — **problem değil**, Capacitor `cap add android` kendi `gradlew` wrapper'ını üretir.
- Bu Windows → iOS build/Xcode buradan çalıştırılamaz; iOS proje dosyaları oluşturulup macOS'a hazır bırakılacak.
- Node v24.8.0 mevcut. `@capacitor/*` henüz kurulu değil (network gerekecek).

## Yapı
```
mobile-app/                      # YENİ — Capacitor projesi (repo kökünde)
├─ package.json                  # @capacitor/core,cli,android,ios
├─ capacitor.config.json         # appId ai.nexus.app, appName "NEXUS", webDir "www"
├─ .gitignore                    # www/, node_modules/, android/build, ios/build, Pods
├─ scripts/build-web.mjs         # public/mobile + public/fonts → www/ (font path rewrite)
├─ assets/icon.png               # uygulama ikonu (public/icon.svg'den üretilecek)
├─ www/                          # OLUŞTURULUR (gitignored) — Capacitor webDir
│  ├─ index.html
│  └─ fonts/...
├─ android/                      # `npx cap add android` üretir
└─ ios/                          # `npx cap add ios` üretir (macOS'a hazır)
```

## Adımlar
1. **`mobile-app/` iskeleti** — `package.json` (Capacitor bağımlılıkları), `capacitor.config.json` (`appId: ai.nexus.app`, `appName: "NEXUS"`, `webDir: "www"`, statusbar/splash ayarları), `.gitignore`.
2. **`scripts/build-web.mjs`** — `public/mobile/index.html` + `public/mobile/tr/*` + `public/fonts/*`'ı `mobile-app/www/`'a kopyalar; tüm `/fonts/...` referanslarını `./fonts/...`'a çevirir (gömülü CSS + HTML içinde). Bu, WebView'in her yolu çözmesinin tek düzeltmesi.
3. **`npm install`** — `@capacitor/core`, `@capacitor/cli`, `@capacitor/android`, `@capacitor/ios`. *(İnternet bağlantısı gerektirir.)*
4. **Bundle üret** — `node scripts/build-web.mjs` → `www/` doluyor.
5. **Uygulama ikonu** — `public/icon.svg` → `scripts/svg2png.exe` ile `assets/icon.png` (1024). Capacitor default ikonuyla da çalışır; ikon opsiyonel iyileştirmedir.
6. **Platform ekle** — `npx cap add android` + `npx cap add ios` → `android/` ve `ios/` dizinleri oluşur, Android için Gradle wrapper dahil.
7. **`npx cap sync`** — `www/`'u her iki platforma kopyalar.
8. **Android'i derle ve çalıştır** — `android_discover_project` → hedef AVD (`pixel_8_api36`) hazır değilse `android_start_emulator` → `android_build_and_run` (build + install + launch). Dönen `output`'u oku, derleme hatası varsa düzelt.
9. **Ekran görüntüsü ile doğrula** — `android_screenshot` ile premium UI'nin emülatörde birebir render olduğunu göster.
10. **README güncelle** — `mobile-app/README.md`: `npm run build:web && npx cap sync`, Android (`npx cap open android` veya `npm run android`), iOS (macOS'ta `pod install` + `npx cap open ios` + Xcode) talimatları.

- iOS fiziksel build burada yapılmaz (Windows); dosyalar macOS'a hazır bırakılır.
- Push notification / camera gibi native plugin'ler eklenmez; saf WebView kabuğu.
