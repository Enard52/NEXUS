# Brand Consistency Guidelines

## Pre-Design Brand Verification Checklist

Before presenting any design, verify every item:

- [ ] Brand colors remain consistent across all screens
- [ ] Typography (font family, weights, sizes) matches established system
- [ ] Icon style (line weight, size, corner radius) is uniform
- [ ] Border radius values follow the token system
- [ ] Shadows and elevation levels are consistent
- [ ] Spacing follows the 8pt grid system
- [ ] Navigation patterns match previous screens
- [ ] Components reuse existing styles (no one-off variations)
- [ ] Motion language (duration, easing) matches established patterns
- [ ] Visual hierarchy is consistent across pages
- [ ] Naming conventions (labels, actions, headings) are consistent
- [ ] Every screen looks like it belongs to the same product

## Rules

- Never introduce a new visual style unless explicitly requested
- If any screen conflicts with the existing design language, redesign it
- Design tokens must be used for all values (never hardcode colors, sizes, or spacing)

## Third-Party Brand Assets

When designs include external companies, brands, services, or products:

### Mandatory Rules
1. Always use official, current brand assets
2. Never redesign, simplify, or reinterpret official logos
3. Never create look-alike logos
4. Never replace official logos with generic icons (unless explicitly requested)
5. Display authentic logos with correct proportions, colors, spacing, and identity
6. Respect each brand's official identity guidelines

### Common Brands (non-exhaustive)
Apple, Google, Android, iOS, Windows, Microsoft, Samsung, Discord, GitHub, Spotify, Netflix, YouTube, OpenAI, Alexa, Philips Hue, TP-Link, Xiaomi, Aqara, Tuya, Home Assistant

### Usage Rules
- Official logos only when contextually appropriate
- Never alter brand colors or proportions
- Maintain required clear space around logos
- Use appropriate logo variants (light/dark mode)
- Never place logos on backgrounds that reduce legibility
